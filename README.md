# scramble

终端词语还原小游戏：把打乱的字母拼回原词。纯标准库，离线运行。

## 玩法

```
$ python -m scramble
===== 词语还原（共 5 轮，每词 3 次机会）=====

—— 第 1/5 轮 ——

打乱后的词：elppa  （5 个字母）
  第 1/3 次猜测：apple
  ✅ 猜对了！答案就是 apple。
...
===== 游戏结束：4/5 =====
👍 不错，继续加油！
```

- 每轮展示一个打乱字母顺序的单词，3 次机会猜出原词
- 默认 5 轮；猜对得 1 分；空输入不计次数
- `Ctrl-D`（EOF）可随时提前结束，按已玩轮数结算

## 用法

| 命令 | 说明 |
|---|---|
| `python -m scramble` | 开始游戏（5 轮） |
| `python -m scramble --rounds 3` | 只玩 3 轮 |
| `python -m scramble --word apple` | 固定用词（演示/测试） |
| `python -m scramble --auto --seed 1` | 自动作答演示，可复现 |
| `python -m scramble --version` | 版本号 |

退出码：全部猜中返回 0；有猜错/提前退出返回 1；参数错误返回 2。

## 设计取舍

- 词库是内置的约 100 个常见英文单词（5–8 字母），不是完整词典
- 打乱算法保证结果与原词不同（最多重试 20 次）
- 默认用 `SystemRandom`（系统熵）；`--seed` 切换为确定性随机，仅用于演示/测试复现

## 已知局限

- 只有英文单词，没有中文谜题
- 猜词是精确匹配，不做拼写纠错或模糊匹配
- 单机游戏，无排行榜、无存档
